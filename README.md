# Bambuddy Desktop для Windows

Неофициальный небольшой клиент: нативное окно Windows с системным WebView2, без установки PWA и без собственного комплекта Chromium. Интерфейс и вход предоставляет ваш сервер Bambuddy.

## Запуск

Скачайте [установщик или переносимый ZIP из Releases](https://github.com/BrainDeLook/bambuddy-desktop/releases/latest).

Установите `Bambuddy Desktop Setup.exe` или распакуйте переносимый ZIP целиком и откройте `Bambuddy Desktop.exe`. Требуются Windows 10/11 x64, .NET Framework 4.8 и [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). Отдельный современный .NET устанавливать не нужно. Установщик работает без прав администратора и добавляет ярлык «Bambuddy Desktop».

При первом запуске введите IP, например `192.168.1.100`, и нажмите «Подключиться». Без порта используется 8000. Также можно указать `192.168.1.100:8000` или полный URL. Полный URL сохраняет указанные протокол, порт и путь, что позволяет работать с HTTPS и обратным прокси.

Войдите через обычную страницу Bambuddy. Клиент запоминает сервер, размер окна, максимизацию и браузерную сессию. Начальный размер окна 1440×960, с ограничением по экрану. На небольшом экране или при увеличенном DPI начальный масштаб подбирается для ширины минимум 1100 CSS-пикселей, чтобы Bambuddy показывал настольный интерфейс. Ctrl+плюс/минус меняют масштаб.

Кнопка «Сервер…» меняет адрес. «Главная» возвращает на сохранённый URL, «Назад» — на предыдущую страницу. Ctrl+R/F5 обновляют страницу, Ctrl+Shift+R/Ctrl+F5 — обновляют без кэша. Ссылки, открываемые пользователем в новом окне, передаются обычному браузеру. Загрузка и выбор файлов используют возможности WebView2.

Настройки и отдельный профиль входа: `%LOCALAPPDATA%\Bambuddy Desktop`. Пароль не хранится в файле настроек; данные сессии сохраняет WebView2. Обычный браузер и его профиль не используются. Удаление программы сохраняет профиль, чтобы повторная установка не сбрасывала вход.

Это оболочка над веб-интерфейсом: потребление памяти зависит от страниц, камер и WebView2. Она не исправляет ошибки сервера и не обещает меньший расход RAM, чем PWA. При закрытии окна WebView2 освобождается; фонового клиента в трее нет.

## Сборка

```
dotnet build BambuddyDesktop.csproj -c Release
```

Для сборки нужен .NET SDK; для запуска — только зависимости выше. Зависимость Microsoft.Web.WebView2 закреплена на стабильной версии 1.0.4314.35. `--self-test` проверяет 16 вариантов адреса, `--browser-test` проверяет инициализацию реального WebView2 и ширину viewport, используя локальную тестовую HTML-страницу без подключения к Bambuddy. Результаты сохраняются рядом с EXE.

Готовый ZIP и проверка реального WebView2:

```powershell
.\build.ps1 -Verify
```

Для сборки установщика установите Inno Setup 6 и выполните `.\build.ps1 -Installer -Verify`. Результаты будут в `dist`. Исходный код клиента распространяется по AGPL-3.0; сведения об иконке и WebView2 — в [THIRD-PARTY.md](THIRD-PARTY.md).

Документация WebView2: https://learn.microsoft.com/microsoft-edge/webview2/concepts/distribution
